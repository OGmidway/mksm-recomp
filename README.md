# MKSM Recomp

An experimental native-PC recompilation project for **Mortal Kombat: Shaolin Monks, NTSC-U retail (SLUS_210.87)**, maintained by [OGmidway](https://github.com/OGmidway), built on [PS2Recomp](https://github.com/ran-j/PS2Recomp).

**Not a playable release yet.** Menus, character/difficulty selection and the opening movie reach scene drawing. First-stage graphics are badly corrupted. The intended Goro's Lair introduction and controllable gameplay remain unverified. Windows is the tested host; portable C++ and Linux/macOS support remain project goals, not verified releases.

## What is included

The modified recompiler, analyzer, C++ runtime, IOP services, runtime debugger, Python investigation tools, focused tests, Ghidra scripts, retail function boundaries and reviewed/candidate symbol metadata. Local generated code, game media and memory dumps are regenerated by contributors.

No ISO, ELF, extracted game assets, prototype executable, proprietary SDK, disassembly dump, memory card, or generated game translation is distributed here. Use your own game copy. Do not attach those files to issues or PRs.

## Quick start

```sh
git clone https://github.com/OGmidway/mksm-recomp.git
cd mksm-recomp
python tools/project.py check
```

Install the prerequisites and place your extracted retail disc in `MortalKombatShaolinMonks/`, then:

```sh
python tools/project.py all --jobs 2
python tools/project.py run
```

This is a substantial source build. Read [BUILDING.md](docs/BUILDING.md) first. The prototype is optional and is not required for retail generation.

| `tools` | Portable contributor setup/build and publication checks |
